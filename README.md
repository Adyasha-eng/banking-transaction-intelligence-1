# Banking Transaction Intelligence Platform

## Project Overview

An end-to-end data analytics and engineering project designed to transform raw banking transaction data into reliable, business-ready insights.

## Business Objectives

- Analyse customer transaction behaviour.
- Monitor transaction volumes and values.
- Identify transaction failures.
- Analyse merchant performance.
- Build reliable and scalable data pipelines.
- Develop business intelligence dashboards.

## Technology Stack

- Microsoft SQL Server
- Python
- Snowflake
- dbt
- Apache Airflow
- Power BI
- Git and GitHub

## Project Architecture

Source Data → Data Ingestion → Data Warehouse → Data Transformation → Data Quality → Orchestration → Business Intelligence

In Progress 🚀
